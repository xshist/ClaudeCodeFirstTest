# Формат диалогов

Диалог — ресурс `DialogueData` (`resources/dialogues/*.tres`):

- `id` — имя диалога;
- `requires` — условия, при которых NPC выберет этот диалог (см. `GameState.check`);
- `script_text` — сценарий, построчно.

## Строки сценария

| Строка | Что делает |
|---|---|
| `marta: Текст реплики` | реплика персонажа (id из `resources/characters/`) |
| `*: Текст` | ремарка рассказчика (курсивом, без портрета) |
| `Просто текст` | тоже ремарка |
| `? Вариант ответа -> метка` | вариант выбора; идущие подряд `?` образуют меню |
| `? Вариант без перехода` | после выбора сценарий идёт дальше за меню |
| `@метка` | метка для переходов |
| `-> метка` / `-> end` | переход / конец диалога |
| `# комментарий` | игнорируется |

## Команды (`!`)

| Команда | Действие |
|---|---|
| `!set флаг` / `!unset флаг` | поставить / снять флаг |
| `!give предмет [кол-во]` / `!take предмет [кол-во]` | выдать / забрать предмет |
| `!count счётчик [+n]` | увеличить счётчик |
| `!quest_start id` / `!quest_done id` | начать / завершить задание |
| `!event имя` | сюжетное событие для `StoryDirector` (после закрытия диалога) |
| `!event_now имя` | то же, но сразу |
| `!sfx звук` | звук из `resources/audio/sound_library.tres` |
| `!heal` | вылечить Кая |
| `!time morning\|day\|evening\|night` | сменить время суток |
| `!if условие [условие...] -> метка` | условный переход (все условия должны выполниться) |
| `!end` | закончить диалог |

## Пример

```
gordey: Опять крысы в амбаре.
? Понял, отец. -> ok
? А может, кошку завести? -> cat
@cat
gordey: Была кошка. Посерела и ушла в лес.
@ok
!give stick
!set talked_father_rats
!event barn_rats
```
